# Spark landing site

Live implementation of the **V1 "Know first."** landing direction, plus the share/unfurl
preview mockups.

- `index.html` — the landing page
- `unfurl.html` — iMessage / X / Slack rich preview mockups and the meta-tag spec
- `assets/` — real product screenshots and the Spark wordmark

Static site, no build step. Type is Poppins (Spark's voice) + Inter (the user's voice).

**Pre-launch material.** `noindex,nofollow` is set on both pages.
